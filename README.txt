Attack Visual (Fabric, Minecraft 1.21.11)
Build: open in IntelliJ IDEA (Gradle import) and run "build" -> jar in build/libs/
Put the jar in .minecraft/mods with Fabric API.
Right Shift = module menu. "Edit HUD" lets you drag Watermark, Coords, Keystrokes, Potions, Armor, Target HUD, Target ESP (Ghosts, Orbs, Crystals, Money).
Modules: Full Bright, Hit Sound, Hit Particles, Hit Marker, Jump Circles,
Keystrokes, Potion HUD, Armor HUD, Crosshair, Info Panel, Screen Theme.

Build without a PC setup: upload this project to a GitHub repo.
Actions tab -> "Build jar" -> download artifact "attackvisual-jar".
